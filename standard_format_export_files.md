# Introduction

This document describes the file format of the output files generated by the `export_data.R` script.

The script exports three types of files:

1. Concentration table
2. Normalized data
3. Normalized data with blank substraction

## Common features of the table files

In all of those files, these are common.

* File format : `xlsx`
* Decimal point : Use point `"."` as the decimal point.
* The table structure is as below, which is almost identical to the input file described in `standard_format_input_file.md`.

| Lines        |      1st     | 2nd column section |
| ------------ | ------------ | ------------------ |
| 1-(x)        |    *empty*   |     Sample info    |
| (x+1) onward | Feature info  |   numeric data    |

### First (x) lines of the 2nd column section for sample information

* The first four lines in the 2nd column section contain `Class`, `File type`, `Injection order` and `Batch ID` data.
* Among them, `Class`, `File type` and `Injection order` contain basically copied data from the input file.

### Starting from the (x+1)th line

* The (x+1)th line is the header line.
* Each line is for one feature/chemical except the header line.
* The 1st column section contains feature information.
* The 2nd column section includes all numeric data.

The feature information column section (1st section) includes the same columns as the input file.

`Alignment ID`,
`Average Rt(min)` and
`Average Mz`.


# Concentration table

## File name

* `(source file name).(normalization method).conc.xlsx`

## Contents

The calibratied concentration values of chemicals (i.e. targeted `Quant`features) in samples of `QC` and `Sample`.
The data of the `QC` samples are presented ahead of the `Sample` samples.
The `Blank` and `Standard` samples and `IS` features are not included in this table.
If any outlier samples are detected, they are not included in this table.

## One batch mode

When there is only one batch, the file has just one spreadsheet.

### First 5 lines of the 2nd column section for sample information

The first 5 lines are `Class`, `File type`, `Injection order`, `Batch ID` and `Given Batch ID`.
`Given Batch ID` is a copy of `Batch ID` from the input file.
`Batch ID` is set to `all`.

### Starting from the 6th line

The feature information column section (1st section) includes additional columns for the concentration data
on top of the columns common to all the tables.

`Chemical`,
`DF%` (detection frequency),
`Samples (d/n)` (detected/total),
`Concentration` (unit),
`LOD`,
`LLOQ`,
`Min Conc.`,
`Max Conc.`,
`Avg. Conc.`,
`R2`,
`Model`,
`Equation`,
`N of points`,
`Target IS`,
`Target IS (Rt)`,
`Slope`

## Multi batch mode

When there are multiple batches, the file has multiple spreadsheets.
The first sheet is `Full`, which contains all batches. 
The rest of the sheets have the data of each batch.

### `Full` sheet

The `Full` sheet contains all batches.

#### First 4 lines of the 2nd column section for sample information

The first 4 lines are `Class`, `File type`, `Injection order` and `Batch ID`.
`Batch ID` is a copy of `Batch ID` from the input file.

#### Starting from the 5th line

The feature information column section (1st section) includes additional columns as below.

`Chemical`,
`DF%`,
`Samples (d/n)` (detected/total),
`Concentration` (unit)

### Sheets for each batch

Each sheet has the data of one batch.
The first 4 lines are `Class`, `File type`, `Injection order` and `Batch ID` like the `Full` sheet.
All the other lines follows the same format as one batch mode tables.


# Normalized/Blank subtracted data tables

## File name

* `(source file name).(normalization method).norm.xlsx`
* `(source file name).(normalization method).norm_blk.xlsx`

## Contents

Values of all features except failed internal standards in samples of `QC` and `Sample`.
The values are normalized or normalized and blank subtracted.
The data of the `QC` samples are presented ahead of the `Sample` samples.
The `Blank` and `Standard` samples are not included in this table.
If any outlier samples are detected, they are not included in this table.

## Table format

### First 5 lines of the 2nd column section for sample information

The first 5 lines are `Class`, `File type`, `Injection order`, `Batch ID` and `Given Batch ID`.
`Given Batch ID` is a copy of `Batch ID` from the input file.
`Batch ID` is set to `all`.

### Starting from the 6th line

The feature information column section (1st section) is a reordered copy of the same section in the input file.

## `closest` RT normalized data

In the feature information column section (1st section), additionally `Target IS` and `Target IS (Rt)` are included. 
The `Target IS` column contains the name of the closest internal standard feature that was used for normalization.
The `Target IS (Rt)` column contains the retention time of the closest internal standard feature.
