# Reports

This directory contains the code to create reports.
A few files are shared among all reports.

* `_quarto.yml`
   : Quarto project configuration file
* `bibliography.bib`
   : References to cite in the reports
* `styles.css`
   : CSS to format fonts of various styles

The reports are defined in the following files:

* `report-external.qmd`
   : Main file for the external report
* `report-internal.qmd`
   : Main file for the internal report
* ~`report-read-msdial.qmd`~
   : Report for reading MS-Dial results. Currently not used.
* `chapters/`
   : Directory containing the individual chapters included in the reports
